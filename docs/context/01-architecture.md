# nx2android — Architecture

This document maps the components, how they connect, and what runs where.

## Component diagram

```mermaid
graph TD
    subgraph PC "On the PC"
        GUI[gui/ PySide6 Desktop App]

    subgraph PorterPipeline "Port pipeline (python -m porter port)"

    end

    GUI -->|--progress json| CLI

    P1 --> P2
    P2 --> P3
    P3 --> P4
    P4 --> P5

    ADB --> APD
    APM -->|loads| RUN
    APD -->|provides data| RUN
```

## Data flow through `pipeline.py` (the core port)

```
Porter.start(options)
  │
  ├── self.nx = nsp.scan(self.o.folder, ...)        # Scan NSP/XCI for games
  │
  ├── for each game:
  │   │
  │   ├── self.g = game.load(tid)                    # Load game profile
  │   ├── self.ap = android_profile.Load(g)          # Load/load fallback android.tsv
  │   │
  │   ├── self.unpack(paths)                         # NSZ/XCZ → NSP in tmp/
  │   ├── self.extract(nx, ...)                      # nx_extract: ExeFS + RomFS
  │   │
  │   ├── self.check_graphics()                      # Must be NVN; check GFPAK/Trinity
  │   ├── self.rewrite(extract/)                     # patch_nso.py → mods/
  │   ├── self.shaders_split(shader/)                # DMSh: Maxwell → SPIR-V
  │   │
  │   ├── self.host_build(extract/, shader/)          # build_ipa_from_nsp.py (port)
  │   │    └── NDK clang compiles host + modules → libdmhost.so
  │   │
  │   ├── self.dmsv_build(shader/)                    # Vulkan shader bundle (.dmsv)
  │   │
  │   ├── self.apk_build()                            # Package APK + sign
  │   └── self.data()                                 # Data pack (RomFS links, env.txt, fonts)
  │
  ├── [self.install()]                                # Optional: push to device via adb
  │
  └── emit_result(r)                               # Final JSON event: paths to APK + data
```

## Key abstractions

### `Options` (pipeline.py)
A dataclass holding every port-time switch: folder, keys, version, language, install flag, fps60, vulkan_driver, mt_replay, touch, external_display, alias_headroom, etc.

### `Profile` (upstream.game / profiles.py)
Per-game metadata stored as TSV in `nxnative/dm/games/<titleID>/`. Contains identity, versions, memory layout, shader split hints, and modules to load.

### `AndroidProfile` (upstream.android_profile)
Game-specific Android keys: status, tested version, package name, orientation, env switches (e.g. `DM_VK_MT_REPLAY=1`). Generated by `build.py` into a C header at port time.

### Porter (`Porter` class in pipeline.py)
The state machine orchestrating all stages. Each stage is a method called in sequence; intermediate results are attributes on self.

## What runs where

| Component | Runs on | Purpose |
|---|---|---|
| `gui/` (PySide6 app) | PC desktop | User interface: choose game folder, watch progress, install, manage saves |
| `porter/` (CLI) | PC | Pipeline orchestration; calls external tools (.NET, NDK, Python scripts) |
| `nx_extract` (.NET) | PC | NSP/XCI extraction using LibHac (.NET) |
| `patch_nso.py` (Python + capstone) | PC | ARM64 static rewrite of game binaries |
| DMSh translator (C# / .NET) | PC | Maxwell shader → SPIR-V translation |
| NDK clang | PC | Compiles the host runtime + game modules into libdmhost.so |
| `mkapk.py` (Python) | PC | Assembles APK and signs it |
| `libdmhost.so` + app code | **Android device** | The actual game runtime: Horizon host, NVN-on-Vulkan replay |
| Game's own code (NSO) | **Android device** | Native ARM64 execution (rewritten for host) |
| Vulkan driver (system or Turnip) | **Android device** | GPU driver that renders the replayed commands |

## External dependencies and toolchain

| Tool | Version | Used by | Shipped? |
|---|---|---|---|
| Android NDK r27c | 27.2.12479018 | Host build (ndk/clang) | No — downloaded by `porter tools --download` |
| .NET SDK 10 | Latest | nx_extract, DMSh translator | No — downloaded by `porter tools --download` |
| platform-tools (adb) | Latest | Install over USB / network | Optional — only needed for `--install` |
| Python 3.11+ | 3.11+ | porter, porter pipeline, engine tools | Yes — bundled in the distributable zip |
| PySide6 | Qt 6.x | GUI only (not needed for CLI) | No — development/runtime dependency |
